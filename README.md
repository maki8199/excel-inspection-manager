# 点検基準管理 Excelツール

数値ラベルによる点検基準管理ツールの仕様書・操作モック・Excel/VBA実装手順をまとめたプロジェクトです。

本番の対象はWindows版デスクトップExcelです。現在は設計と操作見本の段階で、完成したExcelブックやVBAは含みません。HTMLを本番Webアプリとして運用するものではありません。

## 構成

```text
excel-inspection-manager/
├── README.md
├── .gitignore
├── docs/
│   └── requiements.md
├── mock/
│   └── index.html
└── skills/
    └── excel-vba-implementation/
        └── SKILL.md
```

- [業務仕様書](docs/requiements.md)：確定要件、未確定事項、完成時の受入条件。ファイル名は指定の `requiements.md` です。
- [HTML操作モック](mock/index.html)：セット管理・位置別使用履歴・個体の登録や修正・ラベル模擬発行の見本。
- [Excel実装手順スキル](skills/excel-vba-implementation/SKILL.md)：保存と印刷の実機確認から、小さな一連の実装、機能追加、受入までの手順。

## モックの開き方

リポジトリをダウンロードし、`mock/index.html` をChrome、Edge、Safariなどの通常ブラウザーで開いてください。サーバー、Python、Node.js、npm installは不要です。GitHubのファイル表示ではJavaScriptは動作しません。

最初は「使用履歴」を選び、管理No.と位置を切り替えてください。「セット管理」では各枠から個体詳細や登録フォームを開けます。

- 保存→ラベル模擬発行→貼付・照合完了は別の操作です。
- ラベルは個体詳細から即模擬発行します。実プリンターには出力しません。
- 「修正指示」で画面を囲んでコメントし、JSONを書き出せます。AIへの自動送信はしません。
- ファイルの場所が変わると、以前のブラウザー保存コメントを引き継げない場合があります。必要な指示は旧ファイルからJSONで書き出してください。

## 制限

- 業務データは架空のサンプルで、再読込・リセットで初期化されます。
- 計算は測定値±許容差の仮計算で、本番の式ではありません。実際の点検には使用しないでください。
- Excel/VBA、正式な計算、共有保存・排他、実プリンター連携、対象タブレットの本番動作は未実装・未検証です。
- 普段の点検はケースの数値ラベルを目視して行う仕様です。QR点検画面や点検結果入力システムは対象外です。

## Excel実装を依頼するとき

AIまたは開発担当者に次を渡してください。

> `docs/requiements.md` と `skills/excel-vba-implementation/SKILL.md` を読み、`mock/index.html` を操作見本としてExcel/VBA実装を進めてください。未確定事項を推測で本番仕様にせず、まず1個体の登録・保存・実印刷・照合・履歴・再起動まで通してください。

同梱スキルはファイルを読んで利用できます。特定のAIへの自動インストールや、個人環境の別スキルは前提にしません。

## 公開対象

旧Web試作、旧QRモック、DB、バックアップ、修正指示の個別記録、開発環境、テスト出力はこのフォルダーに含めません。モックはCSS・JavaScriptを内包した単一HTMLを正本とし、別のビルド元や生成コマンドはありません。

実業務データ、認証情報、端末固有設定を追加しないでください。将来Excelブックを追加するときは、実データが含まれていないことを確認してください。
